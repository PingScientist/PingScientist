## Selected Work

### NTHU Physics Archive

A full-stack archive system designed for students in the  
Department of Physics at National Tsing Hua University.

The project focuses on making past exams, solutions and course
resources easier to discover, preview, discuss and maintain.

**Current work**

- Course and resource management
- PDF preview and submission workflow
- User contribution records
- Discussion and notification systems
- Responsive desktop and mobile interfaces
- Automated testing and deployment workflows

[Explore the repository →](https://github.com/PingScientist/PastExamWeb_PHY)
