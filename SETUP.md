# Setup

Copy the contents of this folder into the root of the public GitHub profile repository:

```text
PingScientist/PingScientist
```

Then replace this placeholder in `README.md`:

```text
YOUR_MATLAB_REPOSITORY_URL
```

The header animation is a single file, `assets/profile-header-field.svg`, generated by:

```bash
node scripts/profile-header.mjs
```

It has no background, so one file is correct on every GitHub theme and needs no `<picture>` switch. It does not depend on JavaScript, an external statistics service, or a raster banner image, and it honours `prefers-reduced-motion`.

The tags and contact buttons come from the shared token set in `scripts/components.mjs`:

```bash
node scripts/components.mjs write-assets
```
